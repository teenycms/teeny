# Screenshots

All screenshots use the same sample site, "Studio Nara". Desktop images are 2880×1800 (1440×900 at 2× for sharp screens). Phone images are 1170×2532 (390×844 at 3×).

The `thumbs/` folder has small 640×400 JPEG versions of the three screens shown in the main README (Editor, Pages and Style). The full Studio gallery is on the [Teeny website](https://teenycms.github.io/#inside).
